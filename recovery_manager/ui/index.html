Agentic Architecture

5-Agent Collaborative Pipeline + Deterministic Trust Layer

LLM agents are never the single source of truth. They operate within a strictly governed agent network.

01 Intake & Entity Agent

Normalizes multi-report identifiers, SKU/FNSKU mappings, tracking numbers, and charge line items.

02 Policy & Routing Agent
Retrieves exact governing Amazon policy version (V1 pre-Oct 2024 vs V2 post-Oct 2024).
03 Evidence Retriever Agent
Extracts unit custody timeline across Receiving, Prep, Pack, and Returns operational stages.
04 Recovery Decision Agent
Computes 0-100 claimability score, evidence strength rating, and priority levels.
05 Review & Critique Agent
Translates machine logic into clear, human-understandable operational dispute letters.
🛡️ Deterministic Trust Layer
Rule Engine + SLA Window Check + Duplicate Suppression + SHA-256 Audit Hashing.
Security & Compliance

Enterprise-Grade Architecture

🔒 Zero LLM Key Exposure

All LLM provider API keys exist strictly in server environment variables. Browser client code never interacts directly with third-party LLMs.

🏢 Multi-Tenant Data Isolation

Every database query is scoped strictly by organisation identifier (`org_id`). Organisation A can never access Organisation B records.

📜 Cryptographic Audit Trail

Every recommendation maintains a unique SHA-256 checksum incorporating charge fields, policy rules, and evidence citations.
